# 🎹 Guía Rápida - Atajos de Teclado

## Atajos Principales

| Atajo | Acción | Contexto |
|-------|--------|----------|
| `Ctrl+F` | 🔍 Buscar productos | Cualquier momento |
| `Enter` | ✅ Guardar cambios | Durante edición |
| `Esc` | ❌ Cancelar | Durante edición o modal abierto |
| `?` | ❓ Mostrar ayuda | Fuera de campos de texto |

## Flujos de Trabajo Rápidos

### 🏃 Búsqueda Instantánea
```
1. Ctrl+F
2. Escribir término
3. Ver resultados filtrados
```

### ✏️ Editar Nombre
```
1. Click en nombre
2. Escribir nuevo nombre
3. Enter (guardar) o Esc (cancelar)
```

### 💰 Editar Precio
```
1. Click en precio
2. Escribir nuevo precio
3. Enter (guardar) o Esc (cancelar)
```

### 📦 Editar Stock
```
1. Click en ✏️ de variante
2. Escribir nuevo stock
3. Enter (guardar) o Esc (cancelar)
```

### 📝 Gestionar Notas
```
1. Click en ícono de nota
2. Escribir en textarea
3. Click en "Guardar" o Esc (cerrar)
```

## Botón de Ayuda

### Ubicación
- **Esquina inferior derecha**
- Botón azul flotante con "?"
- Siempre visible mientras navegas

### Acceso
- Click en el botón
- O presiona `?` en el teclado

### Contenido
- Lista completa de atajos
- Descripción de cada uno
- Ejemplos de uso
- Tips de productividad

## Tips Pro 💡

### Edición Rápida
- No necesitas hacer click en "Guardar"
- Simplemente presiona `Enter`
- Ahorra tiempo en cada edición

### Búsqueda Eficiente
- `Ctrl+F` selecciona todo el texto
- Empieza a escribir inmediatamente
- No necesitas borrar el texto anterior

### Cancelación Rápida
- `Esc` funciona en cualquier modal
- También cancela ediciones inline
- Forma rápida de "deshacer"

### Navegación Sin Mouse
```
Ctrl+F → Buscar
Tab → Navegar entre campos
Enter → Confirmar
Esc → Cancelar
```

## Solución de Problemas

### El atajo no funciona
1. ✅ Verifica que no estés en un campo de texto (excepto Ctrl+F)
2. ✅ Revisa que no haya extensiones del navegador interfiriendo
3. ✅ Prueba en modo incógnito

### Ctrl+F abre búsqueda del navegador
- Esto es normal, pero nuestro código lo previene
- Si persiste, refresca la página

### ? no muestra ayuda
- Asegúrate de no estar escribiendo en un input
- Presiona Shift+/ (que es ?)
